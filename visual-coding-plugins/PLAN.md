# Visual Coding Plugins 开发计划

当前进度：已实现 8 个 MCP 工具，新增 visual_compare（像素比例、MAE、差异图和区域统计），并接入真实模型反馈和 5 个固定任务的初稿/修订后评测。契约信封保持 0.1.0。下一步扩展多视口、感知指标与应用框架启动器。

## 目标与范围

为 Visual Coding Agent 提供可独立复用的工具，覆盖代码操作、浏览器观察、视觉比较和产物记录。首版服务于本地单页 Web 项目，通过 MCP 暴露工具。

## 核心工具

- **项目操作**：`project.read / patch / run`，读取文件、应用修改、启动与检查项目。
- **页面观察与交互**：`browser.capture / inspect / act`，获取页面或元素截图、DOM／布局信息，执行点击与输入，收集控制台错误。
- **视觉比较**：`visual.compare`，对齐视口并生成差异图、区域变化等结构化证据，供 Agent 判断。
- **产物管理**：`artifact.save`，统一保存截图、日志和比较结果，并关联任务及代码版本。

## 仓库与接口

建议模块：`core/`（契约与生命周期）、`project/`、`browser/`、`visual/`、`artifacts/`、`mcp/`（协议适配）。

统一输入包含 `workspace`、`run_id`、`revision` 和工具参数；统一输出包含 `ok`、`data`、`artifacts`、`error` 和 `duration_ms`。契约在本仓库维护并版本化，Agent 固定兼容版本。工具执行具体操作，任务规划和最终质量判断由 Agent 完成。

## 开发顺序

1. **最小工具集**：实现文件读写、项目启动、浏览器截图和日志返回，支持 Agent 跑通一次生成流程。
2. **反馈工具集**：补充元素定位、局部截图、视觉差异和交互操作；固定视口、截图时机与错误格式。
3. **稳定性与发布**：增加工作目录限制、超时、进程清理和并发隔离；补齐契约示例，发布首个版本并与 Agent 联调。

## 首版验收

工具可脱离 Agent 独立调用；同一页面在固定配置下可重复采集；失败返回明确错误；产物可追溯到代码版本；两个仓库共同跑通 5 个示例任务。
